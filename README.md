# Taskflow — трекер задач

Современный трекер задач для личного планирования. Проект демонстрирует работу с React-компонентами, TypeScript-типизацией, фильтрацией данных и сохранением состояния в браузере.

**Демо:** [zakharovdm.github.io/task-tracker](https://zakharovdm.github.io/task-tracker/)

## Возможности

- Создание задач с названием, описанием и приоритетом
- Фильтрация по статусам и поиск по тексту
- Быстрое изменение статуса задачи
- Счётчики общего числа, активных и завершённых задач
- Сохранение данных в `localStorage`
- Адаптивный интерфейс для компьютеров и мобильных устройств

## Стек

- React 19
- TypeScript
- Vite
- Lucide React
- CSS: стили разделены по назначению

## Локальный запуск

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
```

## Структура проекта

```text
src/
  components/    # переиспользуемые UI-компоненты
  styles/        # базовые, layout-, modal- и адаптивные стили
  App.tsx        # состояние приложения и композиция интерфейса
  types.ts       # TypeScript-типы задач
```

## Публикация

GitHub Actions автоматически собирает и публикует проект на GitHub Pages после каждого push в ветку `main`.
